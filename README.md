# NoGuess

**Epistemic control for AI coding agents.**

Bob can write the code.

NoGuess makes sure nobody silently invented the requirement.

## Problem

Coding agents can produce technically valid implementations while
silently filling missing requirements with plausible assumptions.

The result can be:

> CODE WORKS. WRONG PRODUCT.

## Core workflow

Developer request
→ Evidence collection
→ Interpretation generation
→ Semantic fork detection
→ Clarification when necessary
→ Capability-scoped Bob implementation
→ Independent verification
→ Epistemic Receipt
